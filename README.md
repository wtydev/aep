# AEP — Audio Edit Protocol

**An open protocol for AI-native audio editing.**

AEP enables AI agents and automation tools to inspect, edit, and control audio projects through structured, validated operations.

Inspired by [MEP](https://github.com/adunext/mep), AEP aims to provide a common interface for AI agents to work with audio editors, DAWs, and other audio tools.

- **Editor-agnostic** — Works with any compatible audio application.
- **Agent-agnostic** — No dependency on a specific AI provider.
- **Safe and reversible** — Validated, revision-aware editing operations.
- **Open and extensible** — Designed for interoperability.

> 🚧 **Status:** Early development. Specification and APIs are subject to change.
